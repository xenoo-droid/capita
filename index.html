Cara Akses di Laptop & HP

💡 Cara 1: Buka Lewat Satu Jaringan WiFi / Hotspot

Jika laptop dan HP terhubung ke WiFi atau hotspot yang sama:

  1. Jalankan script python serve.py di laptop.
  2. Script akan menampilkan link IP lokal (misal: http://192.168.1.X:8080).
  3. Buka link tersebut di browser Chrome/Safari HP kamu. Beres!

🚀 Cara 2: Pasang Gratis di GitHub Pages / Vercel (Online 24/7)

Tools ini adalah web app murni (HTML/JS) tanpa database rumit! Kamu bisa upload ke GitHub Pages atau Vercel secara gratis:

Setelah di-hosting, kamu tinggal bookmark link-nya di browser HP atau pilih "Add to Home Screen" agar jadi seperti aplikasi native di HP!

📦 Pindah Data Antar Perangkat

Gunakan tombol Ekspor Data (JSON) di menu "Siklus & Data", lalu kirim file JSON lewat WhatsApp/Telegram ke HP, dan klik Impor Data di HP.
